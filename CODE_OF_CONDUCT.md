# Code of Conduct

## Our commitment

This project aims to be a welcoming, harassment-free space for everyone, regardless of experience, identity, background or ability. We follow the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected behavior

- Be respectful and assume good intent.
- Give specific, constructive feedback about the code, not the person.
- Welcome questions from newcomers and explain project conventions patiently.
- Respect privacy: do not publish another person's contact details, order data or credentials.

## Unacceptable behavior

- Harassment, discrimination, threats, personal attacks or sustained disruption.
- Sexualized language or imagery, and unwelcome attention of any kind.
- Publishing private information without explicit permission.
- Deliberately introducing malware, credential theft or unsafe payment handling.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior violates this code. Reports will be reviewed as privately as practical.

Report conduct concerns privately to the maintainers through GitHub. For abuse hosted on GitHub itself, use GitHub's built-in reporting tools. Do not use a public issue to report a conduct incident.
